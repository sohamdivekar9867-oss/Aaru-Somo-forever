SUPABASE SETUP
1. Run TABLET_SETUP.sql in the Supabase SQL Editor. It safely adds the user_email column if the activity table already exists and backfills emails for existing sessions.
2. Activity tracking records authenticated website sessions. The dashboard shows sessions for aarusaru090901@gmail.com only, and only Somo's account (sohamdivekar9867@gmail.com) is permitted to read the full session table.
3. The dashboard displays the last 3 days. The SQL trigger purges older rows whenever a new session is inserted.
4. For automatic deletion even when nobody visits the site, enable the pg_cron extension in Supabase if available, then run this once in SQL Editor:
   select cron.schedule(
     'delete-old-website-activity',
     '17 * * * *',
     $$delete from public.website_activity_sessions where started_at < now() - interval '3 days'$$
   );
   If pg_cron is not available on your Supabase plan/project, the trigger cleanup still runs when a new session is inserted, but deletion may not happen exactly at the three-day mark during inactivity.
